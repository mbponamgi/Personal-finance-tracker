How to Export Statements
ICICI Bank
1. Login to ICICI NetBanking
2. My Accounts → Account Statement
3. Select date range → Download as Excel/CSV
4. For credit card: Cards → Statement → CSV
Standard Chartered
1. Login to SC Online Banking
2. Accounts → eStatement
3. Select period → Download as CSV
American Express
1. Login to amexindia.com
2. Statements → View/Download
3. Download as CSV (clean format)
ICICI Credit Card
1. Login to ICICI iMobile / NetBanking
2. Cards → Credit Card → Statement
3. Select cycle → Download CSV
